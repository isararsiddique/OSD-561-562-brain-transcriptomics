Figure S6 | Neither flight-associated nor housing-associated junction genes are
functionally or cell-type enriched against the measured gene universe.
All tests use the 1,980 measured genes as background (domain_scope 'custom'),
never the mouse genome. a, Overlap between each query set and the markers of 17
cerebellar classes from the Kozareva et al. atlas (Supplementary Table 2;
padj <= 0.05, logFC > 0, top 200 per subtype by logFC, restricted to the
measured background). Open circles are the overlap expected under the
background, filled circles the observed overlap; classes are ordered by marker
set size. No class reaches BH q <= 0.05 in any set (51 class tests). b, Observed
odds ratio against the smallest odds ratio that could have reached an
uncorrected one-sided Fisher p <= 0.05 for that class and set size. Every point
lies below the identity line, so no observed effect was large enough to be
detectable; the shaded region is where a detectable effect would fall.
c, GO, KEGG and Reactome terms of 5-500 genes plotted as fold enrichment against
-log10 of the uncorrected hypergeometric p (6,682 term tests). The vermilion
line is the Benjamini-Hochberg q <= 0.05 frontier for the largest term family
tested; the dotted line is uncorrected p = 0.05. Zero terms are significant
under g:Profiler's g:SCS correction, and zero under the less conservative BH
recomputation. The strongest term in each set is named: translational initiation
(FLT-GC BY set, 4/10 genes, OR 30.9, uncorrected p = 5.2e-05, BH q = 0.090);
mitochondrion (FLT-GC strongest 106, 24/214, OR 2.7, p = 1.8e-04, q = 0.21);
negative regulation of cell communication (GC-VIV strongest 100, 17/151, OR 2.8,
p = 8.7e-04, q = 0.44). Junction-level change is not expression change, and these
tests ask only whether the gene identities are unusual among measured genes.
