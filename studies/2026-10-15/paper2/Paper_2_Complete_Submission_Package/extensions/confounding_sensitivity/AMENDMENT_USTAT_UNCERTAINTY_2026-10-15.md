# Methodological amendment after the initial diagnostic run

15 October 2026. The initial numerical run exposed a mathematical problem with ordinary percentile bootstrap intervals for noise-corrected centroid moments in this small, high-dimensional sample. Under multinomial resampling, the expectation of the bootstrap U-statistic group Gram matrix is the empirical plug-in Gram matrix G, not the observed corrected matrix G_U. Thus uncentered bootstrap U-statistic percentiles can sit far from the observed U-statistic. This issue was identified while auditing the method, not by selecting an endpoint with a favorable result. The initial numerical results were shared with the parent analyst before correction; their point estimates remain unchanged.

Correction: use E*(G_U*)=G analytically and form centered errors G_U*−G. For the four linear moments (three squared distances and FLT–VIV inner product with GC–VIV), report basic intervals [estimate−q97.5(error), estimate−q2.5(error)]. Save recentered replicate moments G_U+(G_U*−G). The empirical distribution is exploratory finite-sample bootstrap uncertainty; no Gaussian/exact validity is claimed. For nonlinear corrected geometry do not report confidence intervals: ratios of unbiased moment estimates are not unbiased, corrected Gram matrices can be indefinite, and invalid corrected realizations must not be clipped to appear admissible. Save exploratory corrected ratios only for valid 2D contrast Gram matrices, including the invalid-draw fraction. Report corrected moments, not these ratios, in scientific conclusions.

The identification, bias-bound and measured-QC analyses and all seeds/frames remain as frozen in the original plan. This amendment changes only U-statistic uncertainty reporting; it does not add a new scientific endpoint or hypothesis test.

Raw plug-in bootstrap ranges are labeled descriptive resampling quantiles, not confidence intervals: quadratic norms and shared-control moments also have an upward bootstrap sampling contribution. This labeling makes their limited diagnostic role explicit.
