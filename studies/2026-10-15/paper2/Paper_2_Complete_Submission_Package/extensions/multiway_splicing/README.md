# Portable RR23 multiway extension

This is a separately declared retrospective analysis family of the same animals used in the binary junction analysis. Read `RETROSPECTIVE_PLAN_2026-10-15.md` and `SCIENTIFIC_REPORT.md` for selection rules, complete findings, multiplicity, and limits.

## Reproduce offline

From the directory containing this README, set `MW_INPUTS` to a directory containing the original frozen `all_animal_junction_counts.csv.gz` and `animal_metadata.csv`. The source repository uses `research/paper2_beta_20261014/inputs`; a submission package may contain these files in its beta/frozen-input directory. `MW_PYTHON` names a Python installation with NumPy, pandas, SciPy, and Matplotlib. The recorded versions are in `tables/software_versions.json`. The commands below never access the network, and all generated outputs are written in this script-relative directory.

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
MW_INPUTS=/path/to/frozen/input/directory
MW_PYTHON=/path/to/python
"$MW_PYTHON" scripts/select_clusters.py --base "$MW_INPUTS"
"$MW_PYTHON" scripts/analyse.py --base "$MW_INPUTS"
"$MW_PYTHON" scripts/verify_independently.py --base "$MW_INPUTS"
"$MW_PYTHON" scripts/build_outputs.py
```

The bundled `annotation/junction_gene_lookup.csv.gz` contains all retained junctions, including absent gene matches. It is locked to the original count hash and records exact transcript-intron matches to GRCm39 release 112. The source URL and GTF SHA256 are in `annotation/source.json`. The original GTF is only needed to regenerate that lookup from scratch; `select_clusters.py --gtf` supports that initial operation. The bundle provides a lookup for these exact frozen counts rather than a general annotation engine. No gene is assigned by genomic proximity.

## Core deliverables

- `SCIENTIFIC_REPORT.md`: complete methods, results, local positive/null findings, sensitivities, and interpretation.
- `figures/Figure_Multiway.png`, `.pdf`, `.svg`, and `Figure_Multiway_caption.txt`: four-panel figure and caption.
- `tables/selected_cluster_definitions.csv` and `all_candidate_clusters.csv.gz`: all selected and excluded boundary definitions and selection gates.
- `tables/local_exact_results_complete.csv.gz`: all 2,769 local exact tests; full-family and per-contrast BH/BY.
- `tables/global_exact_results.csv` and `global_sensitivity_results.csv`: primary Holm3 and secondary sensitivity families.
- `tables/animal_alternative_compositions.csv.gz`, `all_cluster_three_arm_composition_summaries.csv.gz`, and coverage summaries: every animal and every cluster.
- `tables/three_flight_vivarium_BY_clusters.csv` and the other `three_flight_vivarium_*` files: all three FV BY findings, gene-mapping limits, FG overlap, coordinates, all-arm compositions, entropy, and coverage.
- `tables/junction_overlap.csv` and `overlapping_cluster_pairs.csv`: reused junctions and intersecting boundaries.
- `tables/independent_verification.csv` and `.json`: complete independent numerical checks, including all local exact p values.
- `MANIFEST.csv`: SHA256 and byte size of every artifact except the manifest itself; regenerated by `build_outputs.py`.

Flight animals were collected 14 January 2021; both ground arms 17 January. This confounding limits flight interpretations. No complete-isoform, protein, injury, cell-intrinsic, radiation, or causal-flight claim is supported by local boundary composition alone.
