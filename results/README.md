Every original target, unavailable effect and uncorrected result is retained in the inferential families. The complete tables accompany focused figures; methods/QC variants and shared modalities reuse biological samples. `.csv.gz` files are complete compressed CSV outputs, including whole-genome effects and large mouse-deletion families. Download/decompress these files to inspect them locally.
