The active repository now contains the corrected-panel deposited-count pipeline, complete derived results, publication figure exports, paper-style documentation and primary-source download manifests. Older paper packages and exploratory research folders were removed from the current tree to make the intended study clear.

Earlier commits remain in Git history. The immediately preceding remote revision is [d8c69c034d7eedc1c36ad6b8cd5e78c917ad58dc](https://github.com/isararsiddique/OSD-561-562-brain-transcriptomics/tree/d8c69c034d7eedc1c36ad6b8cd5e78c917ad58dc).
